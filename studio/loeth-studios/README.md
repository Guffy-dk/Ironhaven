# Loeth Studios

## Logo

- `Loeth-Studios.svg` contains the two glass facets, wordmark and studio name as editable vector paths. The artwork is designed for a dark background.
- `Loeth-Studios.psd` has four named transparent raster layers at 1800 × 1620. Use the SVG when you need to edit the outlines or scale for print.
- `Loeth-Studios.png` is the transparent composite for ordinary use.

## Intro

- `Loeth-Studios-Intro.blend` opens in Blender 4.3. The **Animation** scene holds the folded geometry, packed lettering, lighting, camera and keyframes. The **Edit** scene contains the three-second scene strip for trimming and combining with other clips. The scenes use 24 fps.
- `Loeth-Studios-Intro.mp4` is the standalone 960 × 540, three-second export. Ironhaven uses a small offline WebM copy.

The studio identity is independent of any game art. Two ImageGen studies explored a folded L in violet glass. The deliverables use authored vector paths and beveled geometry derived from that direction. The letter outlines use DejaVu Sans and DejaVu Sans Bold.
