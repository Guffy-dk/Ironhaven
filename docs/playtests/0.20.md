# Ironhaven 0.20 interface and building readability

18 November 2026. This update changes the HUD, construction menu, preferences and building presentation.

## Visual changes

- Rounded navy surfaces, consistent border/shadow treatment, Segoe/system typography, construction cards, segmented category tabs and grouped Escape-menu actions. Resource counters remain separate from the shared storage counter.
- Blue painted steel derricks for iron, copper-toned rigs for copper and a coal hopper on coal mines. Roof ribs, texture weathering and moving drill parts remain visible.
- Workshop identity is carried by a painted roof, production symbol and short map name. Smelters use orange/flame, assemblers ochre/gear, foundries steel/I-beam, circuit workshops mint/chip and component factories blue/component. Warehouses use a crate/store identity.
- The same identity map drives the construction buttons, inspector icon, field-guide key and map labels. Roman numerals continue to identify upgrades independently of factory type.
- Type labels are enabled for existing preferences by default. Interface settings can hide them independently of upgrade badges. Labels use screen-space buckets to find room above neighboring buildings and become compact at wider zoom. Unchanged SVG content is reused rather than rebuilt every frame.
- Conveyor arrows use the v0.16 shape, cream color, 0.56 scale, 0.17-tile offset and 0.208 height. Rotation follows the actual outlet in all four directions. Upgrade trim and Roman belt markers remain.
- Training now identifies the blue iron derrick, orange smelter and ochre gear workshop. The field guide includes the trade-symbol key.

## Verification

`npm test`: 192 tests passed. Coverage includes existing preference migration and opt-out, real DOM label controls and persistence, stable label-node reuse, distinct authored roof colors, retained UV/bump detail, and v0.16 conveyor arrow geometry for all four rotations at levels I, VIII and XXI.

The actual embedded game resource is exercised in local Chromium/SwiftShader with a paused in-engine QA colony, not a mockup. The colony includes all three miners and all six authored workshop types. Checks cover 1600×1000, 1280×800 and a compact 900×700 window, shader/page errors, construction cards and the Escape/settings pages. Native Windows startup tests also capture the actual game, creature inspection, island, settings, Escape menu and numbered Dispatch-hub ports.

Raw local screenshots and layout measurements are written to ignored `work/ui-final/`. Native Windows screenshots are generated by `scripts/build-windows.ps1`; the tagged workflow verifies a published installation before promoting the patcher update. The Windows menu screenshot is included as `Ironhaven-menu.png`.

Reproduce:

```sh
npm ci
npm test
npm run build
# On Windows:
./scripts/build-windows.ps1
```
